# База знань українських особових імен (Ukrainian Names Database)

Машиночитна база знань українських особових імен з їхніми варіантами, походженням і транслітерацією латиницею.

База знань була створена на основі третього видання академічного словника-довідника *«Власні імена людей»* Л. Г. Скрипник та Н. П. Дзятківської (Київ: Наукова думка, 2005).

---

## Що всередині

Готова база знань міститься в теці `data/results/`:

- **`ukrainian_names_database.jsonl`** — база даних українських імен;
- **`transliterated_ukrainian_names_database.jsonl`** — ті самі імена з транслітерацією за кількома стандартами.

Усього 905 записів.

Кожен запис містить:
- документальне ім'я;
- офіційні варіанти імені;
- неофіційні (розмовно-побутові, пестливі) варіанти;
- стислу етимологію та походження;
- транслітерацію латиницею за кількома системами.

Дані зберігаються у форматі [JSONL](https://jsonlines.org/) — документоорієнтованому (постреляційному) форматі, що вільно вміщує варіативну, вкладену структуру словникових статей без жорсткої реляційної схеми.

## Алгоритм створення бази знань

Дані сформовано в кілька послідовних етапів:

1. **OCR** Джерельний словник, доступний лише як скан у форматі PDF (відсутній у репозиторії), його конвертовано в Markdown за допомогою Mistral Document AI (див.`data/dictionary/`).
2. **Макропарсинг** (`parsers/macro_parser.py`). Markdown розбивається на окремі статті — по одній на ім'я — і зберігається в `data/parsed_dict/`.
3. **Мікропарсинг** (`parsers/micro_parser.py`). Кожна стаття була розпаршена на структуровані поля — документальне ім'я, його варіанти, походження. Результат — у `data/parsed_entries/`.
4. **Верифікація.** `test_app/app.py` дає інтерфейс для перевірки розпаршених статей із джерелом.
5. **Транслітерація** (`utils/transliterater.py`). Кожне ім'я та його варіанти транслітеровано за кількома стандартами транслітерації засобами бібліотеки [`translit-ua`](https://github.com/dchaplinsky/translit-ua).
6. **Об'єднання.** Базу даних імен і базу даних транслітерацій зведено в єдину базу знань — файли в `data/results/`.
